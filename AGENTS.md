# Repository Instructions

This repository publishes the sanitized, redistributable `kwakdoo8` Pet package.

- Treat every directory under `versions/` as immutable after release.
- Put each visual revision in a new semantic-version directory.
- Keep private pet photos, personal paths, working notes, and rejected generation artifacts out of this repository.
- Validate the full atlas and visually review all states and look directions before updating `LATEST`.
- Keep installation and rollback instructions synchronized with the release layout.
- Do not change the stable Pet ID without documenting it as a breaking change.
